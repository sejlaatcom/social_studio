# تحسين — أداة خطط التحسين المدرسي

أداة ويب عربية تعمل بالكامل داخل المتصفح: تقرأ تقرير الأداء المدرسي (PDF) من منصة تميز، وتحلّل المؤشرات وتصنّفها على المستويات الأربعة، وتبني خطة التحسين وتصدّرها PDF وWord، إضافةً إلى النموذج الإشرافي بمقاس A4 أفقي.

## التشغيل

لا تحتاج الأداة إلى خادم أو قاعدة بيانات أو تثبيت. يكفي تقديم المجلد كملفات ثابتة:

```bash
cd tahseen && python3 -m http.server 8080   # ثم افتح http://localhost:8080
```

ويمكن رفعه كما هو على أي استضافة ثابتة (GitHub Pages، Netlify، Vercel…). المكتبات موجودة داخل `vendor/` (pdf.js 3.11.174 وdocx 8.5.0)، فلا يعتمد التطبيق على أي CDN سوى خط Tajawal من Google Fonts، وعند تعذّر تحميله يُستخدم خط النظام.

| لوحة النتائج: الأداء العام، توزّع المؤشرات على المستويات، المجالات، المعايير، وكل المؤشرات | «لوحة النتائج» |
| قراءة تحليلية: أدنى المؤشرات، المكاسب السريعة، جوانب القوة، وفجوة الإدراك (الاستبانات مقابل النتيجة) | «القراءة التحليلية» |

| بطاقة بيانات المدرسة، وشعار اختياري، وقرار تشكيل الفريق، والاعتماد، ومستويات الأداء القابلة للتعديل | «المدرسة والفريق» |

### محتوى ملف الخطة المصدّر

الغلاف، ثم بطاقة المدرسة، وقرار تشكيل الفريق، ولوحة النتائج، والقراءة التحليلية، والمقارنة (عند توفرها). بعدها لكل مجال فهرس يعرض رقم صفحة كل مؤشر، تليه صفحة مستقلة لكل مؤشر. ويختم الملف بجدول استدامة مؤشرات التقدّم والتميّز، ثم صفحة المتابعة والاعتماد.

- **PDF**: يُبنى مستند HTML بمقاس A4 ويُفتح في نافذة الطباعة، ومنها يُختار «حفظ بتنسيق PDF». بهذه الطريقة يظل النص العربي متجهًا وقابلًا للبحث والتحديد.
- **Word**: ملف ‎.docx‎ قابل للتعديل، بنفس المحتوى والجداول، مع رأس صفحة لهوية المدرسة وترقيم للصفحات.

## مستويات الأداء الافتراضية

| المستوى | النسبة |
|---|---|
| تميّز | 90٪ فأعلى |
| تقدّم | من 75٪ إلى أقل من 90٪ |
| انطلاق | من 50٪ إلى أقل من 75٪ |
| تهيئة | أقل من 50٪ |

يمكن تعديل هذه الحدود من «المدرسة والفريق». المستهدف الافتراضي لكل مؤشر هو عتبة المستوى التالي مضافًا إليها نقطتان، وهو قابل للتعديل.

## البنية

```
tahseen/
  index.html
  css/style.css
  js/framework.js     مستويات الأداء، الهيكل الافتراضي، مكتبة البرامج والمبادرات
  js/parser.js        استخراج نص PDF وتحليله (الرموز، النسب، المجالات، المعايير، بيانات المدرسة)
  js/model.js         نموذج الخطة، الدمج، الحسابات، التحليل، المقارنة، التخزين
  js/export-pdf.js    مستند الطباعة A4 والنموذج الإشرافي A4 أفقي
  js/export-docx.js   تصدير Word
  js/app.js           الواجهة
  vendor/             pdf.js وdocx
```

## ملاحظات

- **التخزين**: تُحفظ الخطط في `localStorage` على الجهاز نفسه. لنقلها إلى جهاز آخر استخدم «تصدير نسخة احتياطية» ثم «استيراد». أما الحفظ السحابي وتسجيل الدخول والترخيص السنوي فتحتاج إلى خادم، ولم تُنفَّذ بعد.
- **قراءة التقارير**: المحلّل يتعرّف على رموز المؤشرات (مثل `1.2.3`) والنسب المئوية في كل سطر، ويدعم الأرقام العربية الهندية والنصوص المستخرجة بترتيب بصري معكوس. إن اختلف تنسيق تقرير ما، فبإمكانك عرض «النص المستخرج» وتصحيح القيم من الجدول، أو الضغط على إحدى «القيم المقروءة» لاختيار النسبة الصحيحة.
- **الملفات الممسوحة ضوئيًا**: التقارير المحفوظة كصور لا تحتوي نصًا، فلا يمكن قراءتها، ويُستخدم لها الإدخال اليدوي.
